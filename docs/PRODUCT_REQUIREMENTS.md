# Product requirements

LyricBook is a privacy-first, local-first concert lyric-book editor, immersive setlist reader, and printable PDF tool. Version `0.0.1` must operate as a static site without an account or backend.

Core requirements:

- import or create song libraries and ordered setlists;
- support optional sections, tags, aliases, sources, confidence, and multiple lyric versions;
- keep original and translated tracks distinct;
- provide English and Simplified Chinese UI;
- save projects locally and export uniquely named backups;
- support immersive previous/next-song navigation;
- expose safe token-based themes;
- print A4 and A5 layouts without clipping content;
- never bundle private or unlicensed lyrics in public presets;
- deploy through tested GitHub Pages artifacts.
