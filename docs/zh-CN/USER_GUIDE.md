# 用户指南

1. 选择内置预设、空白项目或导入文件。
2. 在左侧曲库选择歌曲；“编辑”可修改歌名、别名、标签、版本和语言轨道。
3. 歌单编辑器可选择“结构化编辑”或 “Markdown”。Markdown 中每行填写一项，应用前会保留草稿；切换歌单、关闭窗口或切回结构化编辑时，会先确认是否放弃尚未应用的内容。
4. 主题编辑器可切换“现代工作室”与“雅集书房”两种界面风格，也提供五套离线精选主题。界面风格只保存在当前浏览器，不会写入项目或导出文件；项目主题继续负责颜色、字体与打印样式。选择主题后，它才会作为只读副本加入当前项目；如需修改，可使用“复制并自定义”调整颜色、字体类别、留白、卡片质感、背景纹样和打印配色。
5. 沉浸模式按当前歌单显示上一首／下一首；歌词底部可直接进入下一首。
6. 歌曲阅读页可按当前语言下的歌名打开 Apple Music 或 YouTube 搜索；不会把歌词、别名或标签发送给这些服务。
7. 导出 `.lyricbook` 作为完整备份，也可导出 JSON 或主题。
8. 导入项目文件后先查看预览。默认把文件中的歌词补入当前曲库，保留当前歌单；需要恢复文件中的整套旧项目时，再选择替换当前项目。应用前会自动保留一份本机备份；导入失败不会改动当前项目。

## 新歌单沿用旧歌词

如果你想使用新版预设里的歌单，又想保留之前整理好的歌词：

1. 选择新版预设。当前曲库里已有的歌词会自动带过去。
2. 如果旧歌词还在文件里，打开“导入”，选择旧 `.lyricbook`、LyricBook JSON 或 G.E.M. v4 备份。
3. 查看预览，使用默认的合并歌词操作。当前歌单顺序、项目名称、主题和设置都会保留。
4. 检查歌单与歌词版本，然后导出一份新的 `.lyricbook` 备份。

先导入旧文件、再选择新版预设也可以。选中预设后会使用它的新歌单，并沿用当前曲库中的歌词。

同一首歌的不同歌词版本会分别保留，重复导入相同内容不会不断增加副本。旧文件里有歌词而新歌单没有的歌会留在曲库中，不会自动插入新歌单；没有歌词的旧歌曲不会额外加入。导入文件遇到多个同名候选等无法确定的匹配时，预览会提示并跳过；原文件中的歌词仍然保留，可自行检查后再添加。

选择预设时，如果现有歌词有无法确定的匹配，应用会列出相关歌曲并停止切换，当前项目保持原样。确认歌名和别名后再试即可；不会只带走一部分歌词。

“替换当前项目”适合恢复整份备份，也会恢复备份里的旧歌单与主题。只想补歌词时，使用默认的合并操作即可。处理过程在本机完成，原文件不会被改动，也不会自动下载歌词。

读取文件时可以取消。开始备份和保存后，请等待操作完成；此时窗口会暂时禁止关闭和编辑，避免保存途中丢失修改。

## 编辑与外观

曲库会按当前歌单标明“主流程”“可选曲目”或“仅在曲库”；切换到实演记录时，主流程标签改为“当晚实演”。“仅在曲库”表示歌词仍被保留，但歌曲不在当前演出顺序里。

深圳预设默认使用“固定主流程＋可选点歌”的备歌版。《自由的你》《泡沫》《天空没有极限》属于固定主流程；《画》《失真》《让你知道》作为现场点歌参考，可在打印时取消“包含可选曲目”。9 月 11 日首场实录单独保留，旧版主流程示例已归档。

可选小节中的歌曲会继承小节的可选状态，直到下一个小节。编辑器会显示继承提示：即使“单曲可选”没有勾选，它仍可能因为所属小节而可选。歌单状态、整份说明和歌曲备注也会显示，方便区分演出安排与来源说明。

Markdown 歌单使用标题表示小节，`- [ ] 歌名` 表示可选歌曲，`[note]` 表示备注，`[break]` 表示间隔。编辑器生成的隐藏注释用于保留稳定引用、置信度和来源等结构化信息；未知歌名只会在应用时创建为空歌曲。

查看精选主题不会改写已有或导入的项目。只有主动选择后，主题副本才会保存在项目中；若项目已经使用同名主题 ID，项目自己的版本会被保留，目录原版可通过“复制并自定义”另存。主题设置随项目保存在本地，不会另行下载字体或图片。

新建项目默认使用“影棚岩灰”。旧版内置主题只有在内容与当时发布的原版完全一致时才会自动归入新的五主题目录；用户改过的主题会原样保留。需要回写迁移结果时，应用会先在浏览器中创建本地备份。

在窄屏或 iOS 上，顶栏直接保留打印和沉浸模式；歌单、主题、导入、导出、外观和语言位于“更多操作”菜单。所有项目字段仍可正常编辑并自动保存。

歌词默认只保存在当前浏览器。清理网站数据前请导出备份。
